# SalsaNOW Updater — Mirror

Unmodified mirror of the official **SalsaNOW updater** binary, published so it can be
downloaded from a trusted domain (GitHub) from environments where direct downloads
from the official host are blocked — e.g. the Steam built-in browser inside a
GeForce NOW session.

**SalsaNOW is made by [dpadGuy](https://github.com/dpadGuy).** This mirror is not
affiliated with, endorsed by, or connected to dpadGuy or NVIDIA in any way.
